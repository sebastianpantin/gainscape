## Purpose

Static files Vite copies to the site root unchanged: the web app manifest, the favicon, the generated PNG app icons and iOS launch images, install screenshots and the open font licenses page.

## Map

- `manifest.webmanifest`: hand-written.
- `favicon.svg`, `icons/`, `splash/`: generated by `make icons` from `LOGO` and the palette in `../src/components/pixel-sprites.ts`. Never hand-edit; `make icons-check` (in `make check`) fails when stale.
- `licenses/`: `index.html` (self-contained, inline CSS) and byte-for-byte copies of each `@fontsource` font's LICENSE.
- `screenshots/`: written by `make screenshots`: three narrow (824x1830) and one wide (`train-wide.png`, 1280x800) for the desktop install dialog, each under 200 KB.

## Rules and gotchas

- The manifest, favicon, icons and licenses are precached by the service worker. Screenshots are not: only the browser's install UI fetches them, online. Nor are the iOS launch images in `splash/` (about 390 KB): iOS reads them only at install and launch, so they live outside `icons/`, which `PRECACHED_DIRECTORIES` precaches whole. A new top-level file type may need the precache rules in `../src/pwa/shell-rules.ts`.
- Every `@fontsource/*` family imported in `../src/main.tsx` needs its license file here, copied from `node_modules/@fontsource/<family>/LICENSE`, and a link on `licenses/index.html`.
- Manifest icon, shortcut icon and screenshot paths must exist, shortcut `url`s must be app routes, and `theme_color`/`background_color` must match `index.html`'s theme-color and the `--color-background` token.
- Each manifest shortcut has its own generated icon (`shortcut-*-192.png` from `APP_ICONS` in `../../scripts/icons/render.ts`), and `index.html`'s `<meta name="description">` equals the manifest `description`.
- `index.html` has one portrait `apple-touch-startup-image` link per `SPLASH_SCREENS` entry, hand-written; `tests/web/splash.test.ts` fails when a link, its media query or its file is missing. Without a matching link iOS launches on a blank screen.
- Screenshots are 824x1830 and under 200 KB each.
- Paths are absolute from the site root (`/icons/...`).
