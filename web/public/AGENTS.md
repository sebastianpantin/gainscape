## Purpose

Static files that Vite copies to the site root unchanged: the web app manifest, the favicon, the generated PNG app icons, and the open font licenses page. These are also part of the service worker precache (`manifest.webmanifest`, `favicon.svg`, `icons/`, `licenses/`).

## Key Files

| File                   | Description                                                                                                                                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `manifest.webmanifest` | Hand-written PWA manifest: id `/`, standalone, portrait, colours `#241b13`, icons `icon-192.png`, `icon-512.png` (purpose any) and `maskable-512.png` (maskable), `shortcuts` (Train `/`, Program `/programs/active`, Skills `/skills`, each with `icon-192.png`) and narrow `screenshots` |
| `favicon.svg`          | Generated by `make icons`. Do not hand-edit                                                                                                                                                                                                                                                |
| `icons/`               | Generated PNGs: `apple-touch-icon-180.png`, `favicon-32.png`, `icon-192.png`, `icon-512.png`, `maskable-512.png`. Do not hand-edit                                                                                                                                                         |
| `licenses/index.html`  | Self-contained licenses page (inline CSS) linking the two font licenses; reached from Settings and from `/profile/settings`                                                                                                                                                                |
| `licenses/*-OFL.txt`   | `ibm-plex-mono-OFL.txt` and `pixelify-sans-OFL.txt`, byte-for-byte copies of the `@fontsource` LICENSE files                                                                                                                                                                               |

Not precached by the service worker: only the browser's install UI fetches them, online                                     |

## For AI Agents

### Working In This Directory

- Icons and `favicon.svg` come from `LOGO` and the palette constants in `../src/components/pixel-sprites.ts`, rendered by `../../scripts/icons/`. Change the sprite, then run `make icons`. `make icons-check` (part of `make check`) fails when they are stale.
- Every `@fontsource/*` family imported in `../src/main.tsx` needs its license file here, byte for byte, and a link on `licenses/index.html`.
- Manifest icon, shortcut icon and screenshot `src` paths must exist, shortcut `url`s must be app routes, and `theme_color`/`background_color` must match `index.html`'s theme-color meta and the `--color-background` token.
- Adding a new top-level file type may require updating the precache rules in `../src/pwa/shell-rules.ts`.

### Testing Requirements

- `../../tests/web/manifest.test.ts` checks the manifest and icon files.
- `../../tests/web/licenses.test.ts` checks the license files and page links.
- `../../tests/web/png.test.ts` covers the PNG encoder and icon rendering.
- `../../e2e/pwa/installable.spec.ts` checks installability in a real browser.

Add failing tests to the first two for manifest or license changes (`make test-web`, no stack needed).

### Common Patterns

- Paths in the manifest and HTML are absolute from the site root (`/icons/...`).
