## For AI Agents

### Working In This Directory

- Filename format is `YYYYMMDDHHMMSS_NNN_name.sql`. The timestamp prefix orders migrations, and `NNN` is a three-digit sequence. A new file takes the next number and a timestamp later than the last. Numbers 039 to 041 belong to the `custom-programs` branch; the Grip and Mobility migrations start at 042.
- Never edit or reorder a merged migration. Fix forward with a new file.
- Every new table needs RLS enabled, explicit grants, and coverage in `../tests/` (privileges and self-only tests).
- Server-only helpers belong in the `private` schema.
- `private.is_valid_enrollment` and `private.is_valid_program_position` in 022 (the latter also gates the session link in `complete-session`) restate `validateEnrollment` and `isPositionInSchedule` (`functions/_shared/domain/program-definition.ts`, `program-schedule.ts`). Change them together; `tests/integration/program-enrollments.test.ts` compares the position bounds.
- The `profiles_display_name_visible` check in 036 restates `nameProblem` in `web/src/lib/names.ts` (no control or bidi control characters, not blank once the same blank characters are trimmed). Change both together.
- The `cardio_duration_within_bounds` check in 018 restates the domain rules `countedWorkSeconds` and `intervalDurationSeconds` (`functions/_shared/domain/cardio.ts`) and the `CARDIO_BOUNDS` limits. Change them together, with a new migration for the check.
- After changes: `make reset`, then update the hand-written row types and column lists in `web/src/lib/` and the SQL in `functions/_shared/stores/`.
- Rate-limit buckets named in `functions/_shared/rate-limit.ts` need a row in `private.rate_limit_rules` (seeded in migration 011 and later). `private.take_rate_limit` raises `unknown_rate_limit_bucket` for a missing row.

### Testing Requirements

Write the failing pgTAP test first in the matching file under `../tests/` (or a new numbered file) and run `make test-db`. Behaviour reached through Edge Functions or the REST API goes in `tests/integration/` (for example `rls.test.ts`, `social.test.ts`, `rate-limits.test.ts`). The local stack is required for both.

### Common Patterns

- `create or replace function ... set search_path = ''` with fully qualified names.
- `security definer` functions for cross-user reads, with explicit `revoke` and `grant`.
